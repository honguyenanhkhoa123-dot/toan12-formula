Hướng Dẫn Đưa Lên GitHub Pages (1 Click Có Link Chạy Mọi Máy)

Dự án này được thiết kế theo dạng Static Web App thuần (100% không cần cài đặt Node.js hay Build server phức tạp). Bạn chỉ cần up thư mục này lên GitHub là sẽ có ngay một đường link chạy vĩnh viễn trên bất kỳ điện thoại hay máy tính nào!

1

Tạo Repository mới trên GitHub

Truy cập github.com/new, đặt tên repository (ví dụ: toan12-formula), chọn Public.

2

Đẩy mã nguồn lên GitHub

Mở PowerShell tại thư mục này và chạy các lệnh:

git init
git add .
git commit -m "Full Cong Thuc Toan 12 App"
git branch -M main
git remote add origin https://github.com/TEN_CUA_BAN/toan12-formula.git
git push -u origin main
3

Kích hoạt GitHub Pages

Vào Settings của repo trên GitHub ➔ Chọn mục Pages (menu bên trái) ➔ Tại phần Branch, chọn main và bấm Save.

4

Nhận link chia sẻ cho cả lớp!

Sau 1 phút, GitHub sẽ cấp cho bạn một đường link dạng:

https://TEN_CUA_BAN.github.io/toan12-formula/

🎉 Bất kỳ ai mở link này trên điện thoại (iPhone/Android) hay máy tính đều xem mượt mà, lưu tiến độ học tập riêng của từng bạn!

💾

Quản lý dữ liệu học tập cá nhân

Dữ liệu công thức đã thuộc và yêu thích được lưu tự động trên trình duyệt điện thoại của bạn.
