# 📐 TOÁN 12 PRO - Sổ Tay & Luyện Nhớ Full Công Thức Toán 12

Ứng dụng web học tập thông minh, tra cứu và luyện nhớ toàn bộ công thức Toán 12 ôn thi Tốt Nghiệp THPT Quốc Gia.

Tối ưu chuẩn giao diện điện thoại di động (Mobile-First), thẻ Flashcard 3D, trắc nghiệm ghi nhớ công thức, âm thanh hiệu ứng xúc giác, hoạt động offline và tương thích 100% với **GitHub Pages**.

---

## 🌟 Tính Năng Nổi Bật

1. **📖 Sổ tay Tra Cứu Thông Minh (Cheat Sheet):**
   - Phân loại rõ ràng 8 chuyên đề trọng tâm: *Khảo sát hàm số, Mũ & Logarit, Nguyên hàm - Tích phân, Số phức, Thể tích đa diện, Khối tròn xoay & Mặt cầu, Hệ tọa độ Oxyz, Dãy số & Xác suất*.
   - Hiển thị công thức toán học chuẩn quốc tế bằng KaTeX cực kỳ sắc nét.
   - Kèm mẹo nhớ (Mnemonic) và khẩu quyết dân gian giúp nhớ nhanh không bị quên.
   - Nút **Sao chép công thức** và **Đánh dấu yêu thích (Bookmark)**.

2. **🎴 Thẻ Ghi Nhớ Flashcard 3D (Spaced Repetition):**
   - Mặt trước: Câu hỏi / Tên công thức.
   - Chạm để lật thẻ 3D xem công thức chuẩn và khẩu quyết.
   - Hỗ trợ cử chỉ vuốt (Swipe) trên màn hình cảm ứng điện thoại.
   - Đánh dấu "Đã thuộc" hoặc "Chưa nhớ" để tự động lặp lại theo tiến độ.

3. **🧠 Luyện Trí Nhớ (Formula Quiz):**
   - Bộ câu hỏi trắc nghiệm kiểm tra phản xạ công thức trong 30 giây.
   - Tính điểm, đếm chuỗi đúng (Streak) và giải thích chi tiết từng bước.

4. **📱 Tối ưu 100% cho Điện thoại Di động:**
   - Thanh điều hướng ứng dụng công thái học phía dưới (Bottom Navigation Bar).
   - Chế độ giao diện Tối (Dark Mode) và Sáng (Light Mode) bảo vệ mắt khi ôn thi đêm.
   - Hiệu ứng âm thanh chân thực được tổng hợp trực tiếp bằng Web Audio API.
   - Lưu trữ toàn bộ tiến độ học tập vào `localStorage` trên máy người dùng.

## 🚀 Cách Đưa Lên GitHub Pages Để Có Link Chia Sẻ (1 Phút)

Ứng dụng là **Static Web thuần (HTML/CSS/JS)**, không cần cài đặt Node.js hay build server phức tạp:

### Bước 1: Tạo Repository trên GitHub
1. Đăng nhập [GitHub](https://github.com/) và vào [Tạo Repository Mới](https://github.com/new).
2. Đặt tên (ví dụ: `toan12-formula`), chọn **Public** rồi bấm **Create repository**.

### Bước 2: Đẩy mã nguồn lên
Mở PowerShell hoặc Terminal tại thư mục dự án và chạy:
```bash
git init
git add .
git commit -m "Full Cong Thuc Toan 12 App"
git branch -M main
git remote add origin https://github.com/TEN_GITHUB_CUA_BAN/toan12-formula.git
git push -u origin main
```

### Bước 3: Kích hoạt GitHub Pages
1. Tại trang GitHub repo của bạn, bấm vào **Settings** (bánh răng).
2. Chọn mục **Pages** ở menu bên trái.
3. Tại phần **Build and deployment > Branch**, chọn nhánh `main` (thư mục `/root`) và bấm **Save**.

🎉 **XONG!** Sau 1 phút, bạn sẽ nhận được đường link dạng:
`https://TEN_GITHUB_CUA_BAN.github.io/toan12-formula/`
Gửi link này cho bạn bè là ai cũng mở được ngay trên điện thoại hoặc máy tính!
